## Pages

| `/contact` | Conversational contact form (Web3Forms) |

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment

The contact form posts to [Web3Forms](https://web3forms.com). Create `.env.local`:

```
NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY=your_access_key_here
```

Without it, the form will render and accept input but submission will fail.

## Updating content

Most content lives in plain data arrays, so edits don't require touching layout:

- **Projects** — `components/Projects/ProjectsMain.tsx` (`projectsArray`)
- **Project card art** — `assets/projects/*.svg`, regenerated by the card generator; swap in
  real screenshots by replacing the imports in `assets/projects/ProjectImages.ts`
- **Skills grid** — `components/profile/Skills.tsx` (`skillCategories`)
- **Orbiting skills** — `app/skills/page.tsx` (`skills`)
- **About window** — `components/about/MyInfo.tsx`
- **Resumes** — `public/Shreyas-R-Achar-SDE-Resume.pdf`, `public/Shreyas-R-Achar-ML-Resume.pdf`
